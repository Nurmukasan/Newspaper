# Алматинский вестник

Анимированный газетный спецвыпуск на русском языке. Три вымышленные истории: Нурмукасан в образе Киры против Алтемира/L, потерявшийся в Алматы Зоро и Анеля в образе Резе. Происшествия, свидетельства и статистика — художественный вымысел.

## Запуск

Нужны Node.js 24+ и Python 3. Зависимостей npm нет.

```bash
cd /workspace/Newspaper
npm run check
npm run build
npm run dev
```

Сервер слушает только `127.0.0.1:4173`. Публикуемые файлы находятся в `dist/`; никаких серверных функций или внешних запросов для чтения газеты не требуется. Все пути относительные, включая размещение в `/Newspaper/`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет сайт, собирает артефакт и публикует его после push в `main`.

В настройках репозитория **Settings → Pages → Build and deployment → Source** требуется выбрать **GitHub Actions**. При первом включении после уже сделанного push запустите **Actions → Publish newspaper to GitHub Pages → Run workflow**.

Ожидаемый адрес после успешного deployment: `https://nurmukasan.github.io/Newspaper/`. Наличие workflow само по себе не подтверждает публикацию.

## Содержание и изображения

- `index.html` — полный текст всех историй; основные материалы читаются и без JavaScript.
- `style.css` — адаптивная газетная вёрстка, шрифты, анимация и оформление печати.
- `app.js` — хронология, прогресс чтения, текущий раздел и отключение движения.
- `PRESENTATION.md` — речевое сопровождение ровно на 100 слов, обоснование публицистического стиля, план защиты на пять минут и соответствие четырём критериям задания.
- `assets/images/` — пять фотографий из предоставленного пользователем архива. Лица подписаны как персонажи вымышленной истории. Панорама взрыва — предоставленный фотомонтаж.
- `assets/images/corridor.svg` — авторская художественная реконструкция коридора, **не фотография КБТУ**. Для замены настоящей фотографией измените `src`, `alt` и подпись в `figure.corridor`; сохраняйте авторство и необходимые разрешения источника.
- `scripts/import-photos.py <archive.zip>` — повторный импорт тех же пяти фотографий с проверкой имён и типа. Остальные файлы архива не используются, пути из ZIP не извлекаются напрямую.
- `assets/fonts/` — локальные Cormorant Garamond и Manrope из Google Fonts, лицензии SIL OFL сохранены рядом.

Анимация учитывает `prefers-reduced-motion`. Кнопка в навигации отключает её дополнительно и запоминает выбор, если доступен localStorage. При недоступном хранилище чтение и переключатели работают.

Выпуск посвящён теме «Наука в современном мире» и связан с жизнью КБТУ. На странице есть раздел «Слово редакции» с речевым сопровождением и раскрывающимся разбором стиля. Объём 100 слов относится к этому сопровождению, а не к трём газетным статьям. Пятиминутная защита включает показ газеты, краткую речь и обсуждение примеров; её длительность нужно проверить на репетиции.
