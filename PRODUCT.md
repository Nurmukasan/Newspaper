# Алматинский вестник

Вымышленная газета на русском языке для автора и его друзей. Персонажи представлены пользовательскими косплей-фотографиями: Нурмукасан — Кира, Алтемир — L, мечник — Зоро, Анеля, 18 лет — Резе.

Основная задача читателя: прочитать три истории и сопоставить события через хронологию. Должны работать обычные ссылки на разделы, раскрытие полных текстов и просмотр на телефоне. Без JavaScript доступны статьи и раскрывающиеся тексты.

Публикация — GitHub Pages репозитория Nurmukasan/Newspaper. Никаких пользовательских учётных записей, форм сбора данных, API или серверной базы данных. Фотографии размещаются локально, шрифты также локальные. Имя, возраст, происшествия и цитаты трактуются исключительно как детали художественного сюжета.
